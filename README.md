# 📝 Markdown Previewer

A simple and modern **Markdown Previewer** built with React.js that allows users to write Markdown and instantly see the rendered output in real time.

## 🚀 Features

* ✍️ **Markdown Editor** – Write and edit Markdown content easily.
* 👀 **Live Preview** – Instantly see the rendered Markdown output.
* 🔄 **Synchronized Scrolling** – Keep the editor and preview sections aligned.
* 📥 **Download Markdown** – Download your content as a `.md` file.
* 🎨 **Responsive UI** – Clean and user-friendly interface.
* ⚡ **Fast & Lightweight** – Built using React and Vite.

## 🛠️ Tech Stack

* **React.js**
* **Vite**
* **JavaScript**
* **Material UI**
* **React Icons**
* **Markdown Parser**

### 📁 Components

**`PreviewConfig.jsx`**

The main component of the application. It contains the Markdown editor, preview functionality, synchronized scrolling, and Markdown file download logic.

The component is imported and rendered from `App.jsx`.

### 🎨 Styles

**`MuiStyles.js`**

Contains the Material UI styling configuration used throughout the Markdown Previewer to maintain a consistent and responsive UI.

## ⚙️ Installation

Navigate to the project directory:

```bash
cd markdown-previewer
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.
